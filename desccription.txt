v0.1 - Инициализированы таблицы БД, настроен хэндлер CreateCarHandler для добавления машины

Обращение к серверу:

Везде должны быть JSON с параметрами
    POST /vgarage/create/user --  Добавление нового юзера
    UPDATE

    POST /vgarage/create/car -- Добавление новой машины
    UPDATE
    DELETE vgarage/car/{car_id} -- Удаление машины. {car_id} - id машиниы для удаления
    GET /vgarage/user/{user_id}/car -- получение списка машин у конкретного юзера

    POST /vgarage/create/expense --  Добавление расходов
    UPDATE
    DELETE
